# FitTrack 健身记录 App

一个本地运行的健身记录网页 App，后续可继续封装成安卓端。

## 主要功能

- 首页训练打卡
- 训练部位多选
- 正反面肌肉剖析图
- 根据性别切换肌肉图
- 训练记录本地保存
- 数据统计与部位趋势
- 训练计划、饮食和体重记录
- 每日训练复盘与历史复盘详情

## 本地运行

双击：

```text
启动健身记录App.bat
```

或手动运行：

```powershell
node server.js
```

然后打开：

```text
http://127.0.0.1:4173
```

## 数据说明

当前版本数据保存在浏览器本地。不要清理浏览器网站数据，否则训练记录可能丢失。
